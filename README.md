# G-Rish Pharma Pvt Ltd — Static Website

A responsive, multi-page HTML/CSS/JavaScript website with a pharma-green-and-white visual style.

## Pages
- `index.html` — Home
- `about.html` — About
- `products.html` — Products / API enquiries
- `export.html` — Export & sourcing
- `contact.html` — Contact and enquiry form

## Before publishing
Search for `TODO`, `YOUR_EMAIL`, and bracketed placeholders such as `[Add official company email]`.

1. In `assets/script.js`, replace `YOUR_EMAIL@example.com` with the official company enquiry email.
2. In `contact.html`, replace the placeholder email, WhatsApp/phone number, office address and business hours with approved company details.
3. Review the product categories in `products.html` against your approved catalogue and applicable regulations. The categories provided by the company have been added, but exact product availability, approvals and documentation should be confirmed.
4. Confirm all company descriptions, export markets, capabilities and regulatory statements. The website intentionally does not claim certifications, registrations, product availability or export credentials that were not supplied.
5. Update the page titles/descriptions if your final business positioning changes.
6. For a production form that submits directly on the website, connect a form backend or service and configure spam protection and privacy notices. The current form prepares an email in the visitor's email app and does not transmit/store form data.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy
Upload the folder contents to any static hosting provider, keeping the `assets` folder alongside the HTML files. For Azure Static Web Apps with a plain HTML site, set the app location to `/`, API location blank, and output location blank (unless your repository has a separate build output folder).

## Accessibility and SEO
- Responsive layouts for mobile and desktop
- Semantic page structure and descriptive metadata
- Keyboard-accessible navigation and form controls
